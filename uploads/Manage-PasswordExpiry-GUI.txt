<#
.SYNOPSIS
    Password expiry check, password reset and account unlock across
    FTBCO.FTN.COM and FTBTST.LOCAL - full-screen, light-themed WinForms tool.

.DESCRIPTION
    Four grids, one window:

      1. FIND THE USER. Type a sAMAccountName, a display name or a first name
         and pick the domain (or "Both domains"). "Auto-detect" tries all of
         sAMAccountName, displayName, givenName, sn, UPN and mail, so the same
         box works whatever the service desk was given. Wildcards (*) are
         passed through to LDAP.

      2. MATCHING ACCOUNTS. One row per account with the password verdict:
         EXPIRED (and how long ago), Expires in N day(s), Expires today,
         Must change at next logon, or Never expires - plus whether the
         account is enabled and whether it is currently locked out.

         The verdict comes from msDS-UserPasswordExpiryTimeComputed, which is
         the value the DC itself computes, so it already accounts for a
         fine-grained password policy (PSO) on the user. It is not
         "pwdLastSet + domain maxPwdAge", which is wrong for anybody covered
         by a PSO.

      3. LOCKOUT ON EVERY DOMAIN CONTROLLER. badPwdCount and badPasswordTime
         are NOT replicated between domain controllers, and lockoutTime
         replicates only urgently-but-eventually, so "is this account locked"
         genuinely has a different answer per DC - which DC recorded the bad
         passwords is usually the whole answer to "why does it keep locking".
         The tool therefore queries every DC in the domain, marks the PDC
         emulator (the authoritative one for lockout), and can unlock on all
         of them at once.

         Whether a DC reports the account as locked is read from
         msDS-User-Account-Control-Computed (UF_LOCKOUT), not from a raw
         lockoutTime, because a non-zero lockoutTime whose lockout duration
         has already elapsed is NOT a locked account and reporting it as one
         sends people chasing a lockout that released itself.

      4. RESET THE PASSWORD. The new password is typed twice into masked
         boxes and is checked live against the rules in the requirements
         grid - at least 12 characters, at least one capital, at least one
         number, at least one special character, the two entries matching,
         and the Windows complexity rule that the password may not contain
         the account name or a 3+ character part of the display name. The
         Reset button stays disabled until every requirement is green, so a
         reset is never sent to AD just to be refused with a vague error.

         The reset is written to the PDC emulator (so the new password is
         usable immediately wherever the user authenticates), and can
         optionally force a change at next logon and unlock the account in
         the same action.

    CREDENTIALS. FTBTST.LOCAL is a separate forest and normally rejects the
    logged-on account. Every domain is tried with the current credentials
    first; if that fails, use "Credentials..." to supply an account for that
    domain and the tool keeps it for the session only (in memory - it is
    never written to disk or to the log). The same applies if your day-to-day
    account can read FTBCO but a separate admin account is needed to reset.

    NO RSAT REQUIRED. Everything is done with System.DirectoryServices and
    System.DirectoryServices.AccountManagement, which ship with .NET, so the
    tool runs on a machine that does not have the ActiveDirectory module -
    there is no Get-ADUser, Set-ADAccountPassword or Unlock-ADAccount here.

    Both grids export to CSV / TXT / HTML and every action is written to a
    daily log file next to this script. Passwords are never logged.

.EXAMPLE
    powershell.exe -Sta -ExecutionPolicy Bypass -File .\Manage-PasswordExpiry-GUI.ps1

.EXAMPLE
    powershell.exe -Sta -File .\Manage-PasswordExpiry-GUI.ps1 -Domains FTBCO.FTN.COM

    Open with only one domain in the picker.

.NOTES
    Needs rights to reset passwords / unlock accounts in the target domain -
    reading works with any authenticated account. Scanning every DC in
    FTBCO.FTN.COM means ~29 LDAP queries, so it is a button rather than
    something that happens on every click; it shows progress and can be
    cancelled.
#>

function Write-Log {
    param(
        [string]$Message,
        [ValidateSet('Info', 'Success', 'Warning', 'Error')][string]$Level = 'Info'
    )
    $line = '[{0:yyyy-MM-dd HH:mm:ss}] [{1}] {2}' -f (Get-Date), $Level.ToUpper(), $Message
    try { Add-Content -Path $script:LogFile -Value $line -Encoding UTF8 -ErrorAction Stop } catch { }
    if ($script:TxtLog) {
        $script:TxtLog.AppendText(('{0:HH:mm:ss}  [{1}] {2}{3}' -f (Get-Date), $Level.ToUpper(), $Message, [Environment]::NewLine))
        $script:TxtLog.SelectionStart = $script:TxtLog.TextLength
        $script:TxtLog.ScrollToCaret()
    }
}

function Update-Ui {
    <#
        DoEvents keeps the window responsive during the per-DC scan, but it also
        runs whatever else is queued on this thread. When the tool is started
        from the Exchange menu, left-over handlers from other GUI scripts in the
        same runspace can be sitting in that queue and throw. Those failures are
        not ours, so swallow them instead of letting them surface as an
        unhandled-exception dialog.
    #>
    try { [System.Windows.Forms.Application]::DoEvents() }
    catch {
        $foreign = ($_ | Out-String).Trim() -replace '\s+', ' '
        try { Add-Content -Path $script:LogFile -Value ("[{0:yyyy-MM-dd HH:mm:ss}] [DEBUG] Ignored a queued event from another script: $foreign" -f (Get-Date)) -Encoding UTF8 -ErrorAction SilentlyContinue } catch { }
    }
}

function Set-Status {
    param([string]$Message, [ValidateSet('Info', 'Success', 'Warning', 'Error')][string]$Level = 'Info')
    if (-not $script:LblStatus) { return }
    $script:LblStatus.Text = $Message
    $script:LblStatus.BackColor = switch ($Level) {
        'Success' { $script:Palette.Green }
        'Warning' { $script:Palette.Yellow }
        'Error'   { $script:Palette.Red }
        default   { [System.Drawing.Color]::White }
    }
    Update-Ui
}

function Set-Progress {
    param([int]$Done, [int]$Total)
    if (-not $script:Progress) { return }
    $script:Progress.Maximum = [Math]::Max(1, $Total)
    $script:Progress.Value = [Math]::Min([Math]::Max($Done, 0), $script:Progress.Maximum)
    $script:LblProgress.Text = if ($Total -gt 0) { "$Done of $Total" } else { '' }
    Update-Ui
}

function Get-DomainKey { param([string]$Domain) ([string]$Domain).ToUpperInvariant() }

function Get-DomainCredential {
    <# The credential supplied for this domain this session, or $null. #>
    param([string]$Domain)
    $script:Creds[(Get-DomainKey $Domain)]
}

function New-DirEntry {
    <#
        One place that knows how to bind, so the "current credentials, unless
        the operator supplied some for this domain" rule cannot drift between
        call sites.

        -Server targets one specific domain controller, which is the whole
        point of the lockout scan (and of writing the reset to the PDC);
        without it the DC locator picks whichever DC it likes and the answer
        changes between refreshes.
    #>
    param(
        [Parameter(Mandatory)][string]$Domain,
        [string]$Server,
        [string]$DistinguishedName,
        [switch]$RootDSE
    )
    $target = if ($Server) { $Server } else { $Domain }
    $path =
        if     ($RootDSE)           { "LDAP://$target/RootDSE" }
        elseif ($DistinguishedName) { "LDAP://$target/$DistinguishedName" }
        else                        { "LDAP://$target/" + (Get-DomainInfo -Domain $Domain).DefaultNC }

    $cred = Get-DomainCredential $Domain
    if ($cred) {
        New-Object System.DirectoryServices.DirectoryEntry(
            $path, $cred.UserName, $cred.GetNetworkCredential().Password,
            ([System.DirectoryServices.AuthenticationTypes]::Secure -bor
             [System.DirectoryServices.AuthenticationTypes]::Sealing -bor
             [System.DirectoryServices.AuthenticationTypes]::Signing))
    }
    else {
        New-Object System.DirectoryServices.DirectoryEntry($path)
    }
}

function Get-DsValue {
    <# First value of a DirectorySearcher property, or $null. Never throws. #>
    param($Result, [string]$Name)
    if (-not $Result) { return $null }
    try {
        $p = $Result.Properties[$Name]
        if ($p -and $p.Count -gt 0) { return $p[0] }
    }
    catch { }
    $null
}

function ConvertTo-Int64 {
    param($Value, [long]$Default = 0)
    if ($null -eq $Value) { return $Default }
    try { return [int64]$Value } catch { return $Default }
}

function ConvertFrom-AdFileTime {
    <#
        AD stores these as 100ns ticks since 1601. Three values mean "no date"
        and must not be rendered as 1601-01-01 or as the year 30828:
          0                    never set
          9223372036854775807  never / no expiry
          negative             not a time at all
    #>
    param($Value)
    $n = ConvertTo-Int64 $Value -Default 0
    if ($n -le 0 -or $n -ge [int64]::MaxValue) { return $null }
    try { [datetime]::FromFileTime($n) } catch { $null }
}

function Format-AdDate {
    param($Date)
    if (-not $Date) { return '-' }
    '{0:yyyy-MM-dd HH:mm}' -f $Date
}

function Get-DomainInfo {
    <#
        RootDSE + domain password policy + the domain controller list, fetched
        once per domain per session. Throws on failure so the caller can offer
        the credential prompt - which is the expected outcome for FTBTST.LOCAL
        with the logged-on account.
    #>
    param([Parameter(Mandatory)][string]$Domain, [switch]$Refresh)
    $key = Get-DomainKey $Domain
    if (-not $Refresh -and $script:DomainInfo.ContainsKey($key)) { return $script:DomainInfo[$key] }

    $rootDse = New-DirEntry -Domain $Domain -RootDSE
    # Force the bind: a DirectoryEntry is lazy, so a wrong credential does not
    # fail at New-Object. RefreshCache is used rather than just reading a
    # property because a failed bind leaves Properties null, and the resulting
    # "Cannot index into a null array" hides the real answer, which is "the
    # user name or password is incorrect".
    try { $rootDse.RefreshCache() }
    catch { throw ("Could not bind to {0}: {1}" -f $Domain, (Get-ErrorText $_)) }
    $nc = [string]$rootDse.Properties['defaultNamingContext'][0]
    if (-not $nc) { throw "The directory did not return a defaultNamingContext for $Domain." }
    $boundTo = [string]$rootDse.Properties['dnsHostName'][0]

    $info = @{
        Domain     = $Domain
        DefaultNC  = $nc
        BoundTo    = $boundTo
        MinPwdLen  = 0
        MaxPwdDays = $null
        LockoutMax = 0
        Pdc        = $null
        Dcs        = @()
    }
    $script:DomainInfo[$key] = $info

    # Domain policy. Read through a searcher rather than off the DirectoryEntry
    # because maxPwdAge comes back from a DirectoryEntry as an IADsLargeInteger
    # COM object, which will not cast to [int64].
    try {
        $de = New-DirEntry -Domain $Domain
        $ds = New-Object System.DirectoryServices.DirectorySearcher($de)
        $ds.SearchScope = 'Base'
        $ds.Filter = '(objectClass=*)'
        [void]$ds.PropertiesToLoad.AddRange(@('minpwdlength', 'maxpwdage', 'lockoutthreshold'))
        $r = $ds.FindOne()
        if ($r) {
            $info.MinPwdLen  = [int](ConvertTo-Int64 (Get-DsValue $r 'minpwdlength'))
            $info.LockoutMax = [int](ConvertTo-Int64 (Get-DsValue $r 'lockoutthreshold'))
            $maxAge = ConvertTo-Int64 (Get-DsValue $r 'maxpwdage')
            # Stored as a negative interval; 0 or int64.min means "never expires".
            if ($maxAge -lt 0 -and $maxAge -ne [int64]::MinValue) {
                $info.MaxPwdDays = [int][Math]::Round(([timespan]::FromTicks([Math]::Abs($maxAge))).TotalDays)
            }
        }
    }
    catch { Write-Log ("Could not read the password policy of ${Domain}: " + (Get-ErrorText $_)) 'Warning' }

    $info
}

function Get-DomainControllerList {
    <#
        Every DC in the domain, with its site and a flag for the PDC emulator.
        Cached: it costs a handful of round trips and does not change during a
        support call.
    #>
    param([Parameter(Mandatory)][string]$Domain, [switch]$Refresh)
    $info = Get-DomainInfo -Domain $Domain
    if (-not $Refresh -and $info.Dcs -and $info.Dcs.Count -gt 0) { return $info.Dcs }

    $cred = Get-DomainCredential $Domain
    $ctx = if ($cred) {
        New-Object System.DirectoryServices.ActiveDirectory.DirectoryContext(
            [System.DirectoryServices.ActiveDirectory.DirectoryContextType]::Domain,
            $Domain, $cred.UserName, $cred.GetNetworkCredential().Password)
    }
    else {
        New-Object System.DirectoryServices.ActiveDirectory.DirectoryContext(
            [System.DirectoryServices.ActiveDirectory.DirectoryContextType]::Domain, $Domain)
    }
    $dom = [System.DirectoryServices.ActiveDirectory.Domain]::GetDomain($ctx)
    $pdc = ''
    try { $pdc = [string]$dom.PdcRoleOwner.Name } catch { }
    $info.Pdc = $pdc

    $list = New-Object System.Collections.Generic.List[object]
    foreach ($dc in $dom.DomainControllers) {
        $site = ''
        try { $site = [string]$dc.SiteName } catch { }
        $list.Add([pscustomobject]@{
            Name   = [string]$dc.Name
            Site   = $site
            IsPdc  = ($pdc -and ([string]$dc.Name -eq $pdc))
        })
    }
    # PDC first - it is the DC whose answer is authoritative for lockout.
    $info.Dcs = @($list | Sort-Object -Property @{Expression = 'IsPdc'; Descending = $true}, Site, Name)
    $info.Dcs
}

function Get-PdcName {
    param([Parameter(Mandatory)][string]$Domain)
    $info = Get-DomainInfo -Domain $Domain
    if ($info.Pdc) { return $info.Pdc }
    [void](Get-DomainControllerList -Domain $Domain)
    (Get-DomainInfo -Domain $Domain).Pdc
}

function ConvertTo-LdapValue {
    <#
        Escapes the characters RFC 4515 reserves inside a filter value.
        '*' is deliberately NOT escaped: typing dav* to find davies is exactly
        what the service desk expects from a search box.
    #>
    param([string]$Text)
    $s = [string]$Text
    $s = $s -replace '\\', '\5c'
    $s = $s -replace '\(', '\28'
    $s = $s -replace '\)', '\29'
    $s = $s -replace '\x00', '\00'
    $s
}

function Get-SearchFilter {
    param([string]$Text, [string]$Mode, [bool]$IncludeDisabled)
    $v = ConvertTo-LdapValue $Text
    $core = switch ($Mode) {
        'SamAccountName' { "(|(sAMAccountName=$v)(sAMAccountName=$v*))" }
        'Display name'   { "(displayName=*$v*)" }
        'First name'     { "(givenName=$v*)" }
        default {
            # Auto-detect: the same box has to cope with "49103",
            # "BALOCH, IHTESHAM", "ihtesham" and an email address.
            "(|(sAMAccountName=$v)(sAMAccountName=$v*)(displayName=*$v*)(givenName=$v*)(sn=$v*)(userPrincipalName=$v*)(mail=$v*)(cn=*$v*))"
        }
    }
    $parts = @('(objectCategory=person)', '(objectClass=user)', $core)
    if (-not $IncludeDisabled) {
        # LDAP_MATCHING_RULE_BIT_AND - accounts whose ACCOUNTDISABLE bit is set.
        $parts += '(!(userAccountControl:1.2.840.113556.1.4.803:=2))'
    }
    '(&' + ($parts -join '') + ')'
}

function Get-PasswordVerdict {
    <#
        Turns the raw attributes into the one sentence the caller actually rang
        up about, plus the expiry date behind it.

        msDS-UserPasswordExpiryTimeComputed is the DC's own answer and already
        honours a fine-grained password policy, so it is preferred over
        "pwdLastSet + domain maxPwdAge" - which is simply wrong for anybody in
        a PSO.
    #>
    param($Raw)     # hashtable of lower-cased attribute values

    $uac      = [int](ConvertTo-Int64 $Raw['useraccountcontrol'])
    $uacComp  = [int](ConvertTo-Int64 $Raw['msds-user-account-control-computed'])
    $pwdLast  = ConvertTo-Int64 $Raw['pwdlastset']
    $expRaw   = ConvertTo-Int64 $Raw['msds-userpasswordexpirytimecomputed'] -Default (-1)

    $result = [pscustomobject]@{
        Status    = 'Unknown'
        ExpiresOn = $null
        DaysLeft  = $null
        Severity  = 'Warn'
    }

    if ($pwdLast -eq 0) {
        $result.Status = 'Must change at next logon'
        $result.Severity = 'Warn'
        return $result
    }
    if (($uac -band $UAC_DONT_EXPIRE) -ne 0) {
        $result.Status = 'Never expires'
        $result.Severity = 'Warn'   # not an error, but it is never the intended state
        return $result
    }
    if (($uacComp -band $UAC_PWD_EXPIRED) -ne 0 -and $expRaw -le 0) {
        $result.Status = 'EXPIRED'
        $result.Severity = 'Bad'
        return $result
    }
    if ($expRaw -ge [int64]::MaxValue) {
        $result.Status = 'Never expires'
        $result.Severity = 'Warn'
        return $result
    }
    if ($expRaw -le 0) {
        # No computed value came back (an old DC, or the attribute was not
        # readable). Say so rather than inventing a date.
        $result.Status = 'Unknown (no expiry value)'
        $result.Severity = 'Warn'
        return $result
    }

    $exp = ConvertFrom-AdFileTime $expRaw
    $result.ExpiresOn = $exp
    if (-not $exp) {
        $result.Status = 'Unknown (no expiry value)'
        return $result
    }
    $days = [int][Math]::Floor(($exp - (Get-Date)).TotalDays)
    $result.DaysLeft = $days
    if ($exp -le (Get-Date)) {
        $ago = [int][Math]::Floor(((Get-Date) - $exp).TotalDays)
        $result.Status = if ($ago -le 0) { 'EXPIRED (today)' } else { "EXPIRED ($ago day(s) ago)" }
        $result.Severity = 'Bad'
    }
    elseif ($days -le 0) {
        $result.Status = 'Expires today'
        $result.Severity = 'Warn'
    }
    elseif ($days -le 7) {
        $result.Status = "Expires in $days day(s)"
        $result.Severity = 'Warn'
    }
    else {
        $result.Status = "Expires in $days day(s)"
        $result.Severity = 'Ok'
    }
    $result
}

function ConvertTo-UserRow {
    <# One search hit -> the object the grid, the detail panel and the export all use. #>
    param($Result, [string]$Domain)

    $raw = @{}
    foreach ($a in $USER_ATTRS) { $raw[$a] = Get-DsValue $Result $a }

    $uac     = [int](ConvertTo-Int64 $raw['useraccountcontrol'])
    $uacComp = [int](ConvertTo-Int64 $raw['msds-user-account-control-computed'])
    $verdict = Get-PasswordVerdict $raw

    [pscustomobject]@{
        Domain            = $Domain
        SamAccountName    = [string]$raw['samaccountname']
        DisplayName       = [string]$raw['displayname']
        GivenName         = [string]$raw['givenname']
        Surname           = [string]$raw['sn']
        Mail              = [string]$raw['mail']
        UserPrincipalName = [string]$raw['userprincipalname']
        DistinguishedName = [string]$raw['distinguishedname']
        Department        = [string]$raw['department']
        Title             = [string]$raw['title']
        Enabled           = (($uac -band $UAC_DISABLED) -eq 0)
        # The computed UAC is the only honest source: a stale lockoutTime whose
        # lockout duration has already elapsed is NOT a locked account.
        LockedOut         = (($uacComp -band $UAC_LOCKOUT) -ne 0)
        LockoutTime       = ConvertFrom-AdFileTime $raw['lockouttime']
        BadPwdCount       = [int](ConvertTo-Int64 $raw['badpwdcount'])
        BadPasswordTime   = ConvertFrom-AdFileTime $raw['badpasswordtime']
        PasswordLastSet   = ConvertFrom-AdFileTime $raw['pwdlastset']
        PasswordNeverExpires = (($uac -band $UAC_DONT_EXPIRE) -ne 0)
        PasswordNotRequired  = (($uac -band $UAC_PWD_NOTREQD) -ne 0)
        CannotChangePassword = (($uac -band $UAC_PWD_CANTCHANGE) -ne 0)
        AccountExpires    = ConvertFrom-AdFileTime $raw['accountexpires']
        LastLogon         = ConvertFrom-AdFileTime $raw['lastlogontimestamp']
        WhenCreated       = $(try { [datetime]$raw['whencreated'] } catch { $null })
        Pso               = $(if ($raw['msds-resultantpso']) { ([string]$raw['msds-resultantpso'] -replace '^CN=([^,]+),.*$', '$1') } else { '' })
        PwdStatus         = $verdict.Status
        PwdExpiresOn      = $verdict.ExpiresOn
        PwdDaysLeft       = $verdict.DaysLeft
        PwdSeverity       = $verdict.Severity
    }
}

function Search-DomainUsers {
    <#
        Searches ONE domain. Returns a hashtable
        @{ Rows = @(); Error = '<text>'; Truncated = $true/$false }
        and never throws - a domain that cannot be reached must not stop the
        other domain from producing results.
    #>
    param(
        [Parameter(Mandatory)][string]$Domain,
        [Parameter(Mandatory)][string]$Text,
        [string]$Mode = 'Auto-detect',
        [bool]$IncludeDisabled = $false,
        [int]$Limit = 300
    )
    $out = @{ Rows = @(); Error = ''; Truncated = $false }
    $searcher = $null
    try {
        $root = New-DirEntry -Domain $Domain
        $searcher = New-Object System.DirectoryServices.DirectorySearcher($root)
        $searcher.Filter = Get-SearchFilter -Text $Text -Mode $Mode -IncludeDisabled $IncludeDisabled
        $searcher.PageSize = 200
        $searcher.SizeLimit = $Limit
        $searcher.ClientTimeout = [timespan]::FromSeconds(60)
        [void]$searcher.PropertiesToLoad.AddRange($USER_ATTRS)
        Write-Log "Searching ${Domain}: $($searcher.Filter)" 'Info'

        $rows = New-Object System.Collections.Generic.List[object]
        $found = $searcher.FindAll()
        try {
            foreach ($r in $found) {
                if ($rows.Count -ge $Limit) { $out.Truncated = $true; break }
                $rows.Add((ConvertTo-UserRow -Result $r -Domain $Domain))
            }
        }
        finally { $found.Dispose() }
        $out.Rows = $rows.ToArray()
    }
    catch {
        $out.Error = Get-ErrorText $_
    }
    finally { if ($searcher) { $searcher.Dispose() } }
    $out
}

function Get-UserOnDc {
    <#
        Re-reads one account from ONE named domain controller. A base-scope
        search on the DN is the cheapest possible query and asks that exact DC
        rather than whichever one the locator fancies.

        Returns @{ Ok = $bool; Error = '...'; <values> }.
    #>
    param(
        [Parameter(Mandatory)][string]$Domain,
        [Parameter(Mandatory)][string]$Server,
        [Parameter(Mandatory)][string]$DistinguishedName,
        [int]$TimeoutSeconds = 8
    )
    $searcher = $null
    try {
        $de = New-DirEntry -Domain $Domain -Server $Server -DistinguishedName $DistinguishedName
        $searcher = New-Object System.DirectoryServices.DirectorySearcher($de)
        $searcher.SearchScope = 'Base'
        $searcher.Filter = '(objectClass=*)'
        $searcher.ClientTimeout = [timespan]::FromSeconds($TimeoutSeconds)
        $searcher.ServerTimeLimit = [timespan]::FromSeconds($TimeoutSeconds)
        [void]$searcher.PropertiesToLoad.AddRange($DC_ATTRS)
        $r = $searcher.FindOne()
        if (-not $r) { return @{ Ok = $false; Error = 'The object was not found on this DC (replication?)' } }

        $uacComp = [int](ConvertTo-Int64 (Get-DsValue $r 'msds-user-account-control-computed'))
        @{
            Ok              = $true
            Error           = ''
            LockedOut       = (($uacComp -band $UAC_LOCKOUT) -ne 0)
            LockoutTime     = ConvertFrom-AdFileTime (Get-DsValue $r 'lockouttime')
            BadPwdCount     = [int](ConvertTo-Int64 (Get-DsValue $r 'badpwdcount'))
            BadPasswordTime = ConvertFrom-AdFileTime (Get-DsValue $r 'badpasswordtime')
            PasswordLastSet = ConvertFrom-AdFileTime (Get-DsValue $r 'pwdlastset')
        }
    }
    catch { @{ Ok = $false; Error = (Get-ErrorText $_) } }
    finally { if ($searcher) { $searcher.Dispose() } }
}

function Unlock-UserOnDc {
    <#
        Clearing lockoutTime is what an unlock IS - there is no separate
        operation in the protocol; Unlock-ADAccount writes the same zero.
    #>
    param(
        [Parameter(Mandatory)][string]$Domain,
        [Parameter(Mandatory)][string]$Server,
        [Parameter(Mandatory)][string]$DistinguishedName
    )
    $de = $null
    try {
        $de = New-DirEntry -Domain $Domain -Server $Server -DistinguishedName $DistinguishedName
        $de.Properties['lockoutTime'].Value = 0
        $de.CommitChanges()
        @{ Ok = $true; Error = '' }
    }
    catch { @{ Ok = $false; Error = (Get-ErrorText $_) } }
    finally { if ($de) { $de.Dispose() } }
}

function Set-UserPasswordOnDc {
    <#
        Two ways of doing the same thing, because neither works everywhere:

        1. System.DirectoryServices.AccountManagement. It negotiates the
           sealed/signed connection the DC demands for a password write, and
           takes alternate credentials cleanly across a forest boundary.
        2. IADsUser::SetPassword through DirectoryEntry.Invoke, which falls
           back to the legacy NetUserSetInfo path.

        If the first fails for a reason that is not "the password was
        rejected", the second is tried before giving up.
    #>
    param(
        [Parameter(Mandatory)][string]$Domain,
        [Parameter(Mandatory)][string]$Server,
        [Parameter(Mandatory)][string]$DistinguishedName,
        [Parameter(Mandatory)][string]$SamAccountName,
        [Parameter(Mandatory)][string]$NewPassword
    )
    $cred = Get-DomainCredential $Domain
    $firstError = ''

    $ctx = $null; $up = $null
    try {
        $ctx = if ($cred) {
            New-Object System.DirectoryServices.AccountManagement.PrincipalContext(
                [System.DirectoryServices.AccountManagement.ContextType]::Domain,
                $Server, $cred.UserName, $cred.GetNetworkCredential().Password)
        }
        else {
            New-Object System.DirectoryServices.AccountManagement.PrincipalContext(
                [System.DirectoryServices.AccountManagement.ContextType]::Domain, $Server)
        }
        $up = [System.DirectoryServices.AccountManagement.UserPrincipal]::FindByIdentity(
            $ctx, [System.DirectoryServices.AccountManagement.IdentityType]::DistinguishedName, $DistinguishedName)
        if (-not $up) {
            $up = [System.DirectoryServices.AccountManagement.UserPrincipal]::FindByIdentity(
                $ctx, [System.DirectoryServices.AccountManagement.IdentityType]::SamAccountName, $SamAccountName)
        }
        if ($up) {
            $up.SetPassword($NewPassword)
            return @{ Ok = $true; Error = ''; Method = 'AccountManagement' }
        }
        $firstError = 'The account was not found through AccountManagement.'
    }
    catch { $firstError = Get-ErrorText $_ }
    finally {
        if ($up) { $up.Dispose() }
        if ($ctx) { $ctx.Dispose() }
    }

    # A rejected password is a final answer - retrying the other way only
    # produces a second, less helpful error message.
    if ($firstError -match '(?i)password does not meet|complexity|history|length requirement') {
        return @{ Ok = $false; Error = $firstError; Method = 'AccountManagement' }
    }

    $de = $null
    try {
        $de = New-DirEntry -Domain $Domain -Server $Server -DistinguishedName $DistinguishedName
        [void]$de.Invoke('SetPassword', @($NewPassword))
        $de.CommitChanges()
        @{ Ok = $true; Error = ''; Method = 'IADsUser::SetPassword' }
    }
    catch {
        $second = Get-ErrorText $_
        @{ Ok = $false; Method = 'both'; Error = "AccountManagement: $firstError | IADsUser::SetPassword: $second" }
    }
    finally { if ($de) { $de.Dispose() } }
}

function Set-MustChangeAtLogon {
    param(
        [Parameter(Mandatory)][string]$Domain,
        [Parameter(Mandatory)][string]$Server,
        [Parameter(Mandatory)][string]$DistinguishedName
    )
    $de = $null
    try {
        $de = New-DirEntry -Domain $Domain -Server $Server -DistinguishedName $DistinguishedName
        # 0 = must change at next logon. (-1 would mean "set to now".)
        $de.Properties['pwdLastSet'].Value = 0
        $de.CommitChanges()
        @{ Ok = $true; Error = '' }
    }
    catch { @{ Ok = $false; Error = (Get-ErrorText $_) } }
    finally { if ($de) { $de.Dispose() } }
}

function Get-RequiredLength {
    <#
        The tool's own floor is 12. A domain that demands MORE wins; a domain
        that demands less does not lower it.
    #>
    param([string]$Domain)
    $min = $MinPasswordLength
    if ($Domain) {
        try {
            $d = $script:DomainInfo[(Get-DomainKey $Domain)]
            if ($d -and $d.MinPwdLen -gt $min) { $min = $d.MinPwdLen }
        }
        catch { }
    }
    $min
}

function Test-ContainsAccountName {
    <#
        The Windows complexity rule nobody remembers: the password may not
        contain the sAMAccountName, nor any 3+ character chunk of the display
        name delimited by spaces, commas, dots, hyphens or underscores.
        Checking it here turns a vague "the password does not meet the
        requirements" from the DC into a specific reason before anything is
        sent.
    #>
    param([string]$Password, $User)
    if (-not $Password -or -not $User) { return $false }
    $p = $Password.ToLowerInvariant()
    $sam = [string]$User.SamAccountName
    if ($sam -and $sam.Length -ge 3 -and $p.Contains($sam.ToLowerInvariant())) { return $true }
    foreach ($token in ([string]$User.DisplayName -split '[\s,\.\-_#]+')) {
        if ($token -and $token.Length -ge 3 -and $p.Contains($token.ToLowerInvariant())) { return $true }
    }
    $false
}

function Get-PasswordRuleRows {
    <#
        The requirements grid. Returns one row per rule with an OK / Missing
        verdict; Test-PasswordAcceptable below is what the Reset button reads,
        so the grid and the button can never disagree.
    #>
    param([string]$Password, [string]$Confirm, $User)

    $min = Get-RequiredLength ($(if ($User) { $User.Domain } else { '' }))
    $typed = [bool]$Password
    function New-RuleRow {
        param([string]$Requirement, [bool]$Met, [string]$Detail = '')
        [pscustomobject]@{
            Requirement = $Requirement
            Status      = if (-not $typed) { 'n/a' } elseif ($Met) { 'OK' } else { 'Missing' }
            Met         = $Met
            Detail      = $Detail
        }
    }

    @(
        New-RuleRow "At least $min characters" ($Password.Length -ge $min) `
            $(if ($typed) { "$($Password.Length) typed" } else { '' })
        New-RuleRow 'At least 1 capital letter (A-Z)'      ($Password -cmatch '[A-Z]')
        New-RuleRow 'At least 1 number (0-9)'              ($Password -match '[0-9]')
        New-RuleRow 'At least 1 special character'         ($Password -match '[^a-zA-Z0-9]') '! @ # $ % ^ & * etc.'
        New-RuleRow 'Both entries match'                   ($typed -and $Password -ceq $Confirm)
        New-RuleRow 'Does not contain the account or name' (-not (Test-ContainsAccountName -Password $Password -User $User)) `
            'Windows complexity rule'
    )
}

function Test-PasswordAcceptable {
    param([string]$Password, [string]$Confirm, $User)
    if (-not $Password) { return $false }
    $rows = Get-PasswordRuleRows -Password $Password -Confirm $Confirm -User $User
    -not (@($rows | Where-Object { -not $_.Met }).Count)
}

function Set-CellWash {
    <#
        Colours one cell AND remembers the colour on the cell, so the
        CellPainting handler added after Set-Gui3DTheme can keep the colour
        visible when the row is selected (see the note where it is wired up).
    #>
    param($Cell, $Color)
    if (-not $Cell) { return }
    $Cell.Style.BackColor = $Color
    $Cell.Style.SelectionBackColor = $Color
    $Cell.Style.SelectionForeColor = $script:Palette.Text
    $Cell.Tag = $Color
}

function Get-SeverityColor {
    param([string]$Severity)
    switch ($Severity) {
        'Ok'   { $script:Palette.Green }
        'Bad'  { $script:Palette.Red }
        'Warn' { $script:Palette.Yellow }
        'Info' { $script:Palette.Info }
        default { [System.Drawing.Color]::White }
    }
}

function Render-Users {
    if (-not $script:GridUsers) { return }
    $script:GridUsers.SuspendLayout()
    $script:GridUsers.Rows.Clear()
    $i = 0
    foreach ($u in $script:Users) {
        $i++
        $idx = $script:GridUsers.Rows.Add(
            $i,
            $u.Domain,
            $u.SamAccountName,
            $u.DisplayName,
            $(if ($u.Enabled) { 'Enabled' } else { 'DISABLED' }),
            $u.PwdStatus,
            (Format-AdDate $u.PasswordLastSet),
            (Format-AdDate $u.PwdExpiresOn),
            $(if ($null -ne $u.PwdDaysLeft) { $u.PwdDaysLeft } else { '-' }),
            $(if ($u.LockedOut) { 'LOCKED' } else { 'No' }),
            $u.Mail
        )
        $row = $script:GridUsers.Rows[$idx]
        $row.Tag = $u
        Set-CellWash $row.Cells[4] $(if ($u.Enabled) { $script:Palette.Green } else { $script:Palette.Red })
        Set-CellWash $row.Cells[5] (Get-SeverityColor $u.PwdSeverity)
        Set-CellWash $row.Cells[9] $(if ($u.LockedOut) { $script:Palette.Red } else { $script:Palette.Green })
        $row.Cells[3].ToolTipText = "$($u.DistinguishedName)`r`nUPN: $($u.UserPrincipalName)"
    }
    $script:GridUsers.ClearSelection()
    $script:GridUsers.ResumeLayout()

    $expired = @($script:Users | Where-Object { $_.PwdSeverity -eq 'Bad' }).Count
    $soon    = @($script:Users | Where-Object { $_.PwdSeverity -eq 'Warn' }).Count
    $locked  = @($script:Users | Where-Object { $_.LockedOut }).Count
    $script:LblUsers.Text = 'Accounts: {0}   |   Expired / must change: {1}   |   Expiring soon or never expires: {2}   |   Locked: {3}' -f `
        $script:Users.Count, $expired, $soon, $locked
}

function Render-Dcs {
    if (-not $script:GridDcs) { return }
    $script:GridDcs.SuspendLayout()
    $script:GridDcs.Rows.Clear()
    $i = 0
    foreach ($d in $script:DcRows) {
        $i++
        $idx = $script:GridDcs.Rows.Add(
            $i,
            $d.Dc,
            $d.Site,
            $(if ($d.IsPdc) { 'PDC emulator' } else { '' }),
            $(if ($d.Reachable) { 'Yes' } else { 'No' }),
            $d.LockState,
            (Format-AdDate $d.LockoutTime),
            $(if ($d.Reachable) { $d.BadPwdCount } else { '-' }),
            (Format-AdDate $d.BadPasswordTime),
            (Format-AdDate $d.PasswordLastSet),
            $d.Note
        )
        $row = $script:GridDcs.Rows[$idx]
        $row.Tag = $d
        Set-CellWash $row.Cells[4] $(if ($d.Reachable) { $script:Palette.Green } else { $script:Palette.Red })
        Set-CellWash $row.Cells[5] $(
            if (-not $d.Reachable)       { $script:Palette.Yellow }
            elseif ($d.LockState -eq 'LOCKED') { $script:Palette.Red }
            else                          { $script:Palette.Green })
        if ($d.IsPdc) { Set-CellWash $row.Cells[3] $script:Palette.Info }
        if ($d.Note) { $row.Cells[10].ToolTipText = $d.Note }
    }
    $script:GridDcs.ClearSelection()
    $script:GridDcs.ResumeLayout()

    $checked = @($script:DcRows | Where-Object { $_.Reachable }).Count
    $locked  = @($script:DcRows | Where-Object { $_.Reachable -and $_.LockState -eq 'LOCKED' }).Count
    $bad     = ($script:DcRows | Where-Object { $_.Reachable } | Measure-Object -Property BadPwdCount -Sum).Sum
    if ($null -eq $bad) { $bad = 0 }
    if ($script:DcRows.Count -eq 0) {
        # "0 locked out of 0 checked" is not a clean bill of health, it is no
        # answer at all - say which one it is.
        $script:LblDcs.Text = 'No domain controller has been queried yet.'
    }
    else {
        $script:LblDcs.Text = 'DCs listed: {0}   |   Answered: {1}   |   Reporting LOCKED: {2}   |   Bad password attempts recorded: {3}' -f `
            $script:DcRows.Count, $checked, $locked, $bad
    }
}

function Render-Rules {
    if (-not $script:GridRules) { return }
    $script:Rules = Get-PasswordRuleRows -Password $script:TxtPwd1.Text -Confirm $script:TxtPwd2.Text -User $script:Selected
    $script:GridRules.SuspendLayout()
    $script:GridRules.Rows.Clear()
    foreach ($r in $script:Rules) {
        $idx = $script:GridRules.Rows.Add($r.Requirement, $r.Status, $r.Detail)
        $wash = switch ($r.Status) {
            'OK'      { $script:Palette.Green }
            'Missing' { $script:Palette.Red }
            default   { [System.Drawing.Color]::White }
        }
        Set-CellWash $script:GridRules.Rows[$idx].Cells[1] $wash
    }
    $script:GridRules.ClearSelection()
    $script:GridRules.ResumeLayout()
    Update-ActionState
}

function Update-CredBanner {
    if (-not $script:LblCreds) { return }
    $supplied = @($script:Creds.Keys | Sort-Object)
    if ($supplied.Count -eq 0) {
        $script:LblCreds.Text = 'Signed in as ' + $env:USERDOMAIN + '\' + $env:USERNAME
        $script:LblCreds.BackColor = $script:Palette.Info
    }
    else {
        $parts = foreach ($k in $supplied) { '{0} = {1}' -f $k, $script:Creds[$k].UserName }
        $script:LblCreds.Text = 'Alternate credentials: ' + ($parts -join '   |   ')
        $script:LblCreds.BackColor = $script:Palette.Green
    }
}

function Update-SelectedBanner {
    if (-not $script:LblUser) { return }
    if (-not $script:Selected) {
        $script:LblUser.Text = 'No account selected - click a row in the accounts grid.'
        $script:LblUser.BackColor = $script:Palette.Yellow
        return
    }
    $u = $script:Selected
    # Two lines on purpose: on one line the account and the name pushed the
    # verdict - the part that decides what to do next - off the end of the
    # label, where it was clipped rather than wrapped.
    $line1 = '{0}\{1}   -   {2}' -f ($u.Domain -split '\.')[0], $u.SamAccountName, $u.DisplayName
    $bits = @(
        $u.PwdStatus
        $(if ($u.LockedOut) { 'LOCKED' } else { 'not locked' })
        $(if ($u.Enabled) { 'enabled' } else { 'DISABLED' })
    )
    if ($u.Pso) { $bits += "PSO: $($u.Pso)" }
    $script:LblUser.Text = $line1 + [Environment]::NewLine + ($bits -join '   |   ')
    $script:LblUser.BackColor = switch ($u.PwdSeverity) {
        'Bad'  { $script:Palette.Red }
        'Warn' { $script:Palette.Yellow }
        default { $script:Palette.Green }
    }
}

function Update-ActionState {
    <# Reset and Unlock are only ever clickable when they can actually work. #>
    if ($script:Busy) { return }
    $have = [bool]$script:Selected
    if ($script:BtnUnlock) { $script:BtnUnlock.Enabled = $have }
    if ($script:BtnReset) {
        $script:BtnReset.Enabled = $have -and
            (Test-PasswordAcceptable -Password $script:TxtPwd1.Text -Confirm $script:TxtPwd2.Text -User $script:Selected)
    }
}

function Set-DomainCredential {
    <# Prompt for, store (in memory only) and verify a credential. #>
    param([string]$Domain, [string]$Reason)
    $cred = Request-DomainCredential -Domain $Domain -Reason $Reason
    if (-not $cred) { Set-Status 'Credential prompt cancelled.' 'Info'; return $false }

    $key = Get-DomainKey $Domain
    $previous = $script:Creds[$key]
    $script:Creds[$key] = $cred
    # A stored credential changes who the cached RootDSE / DC list belongs to.
    $script:DomainInfo.Remove($key)
    try {
        $info = Get-DomainInfo -Domain $Domain -Refresh
        Write-Log "Credentials accepted for $Domain as $($cred.UserName) (bound to $($info.BoundTo))." 'Success'
        Set-Status "Credentials accepted for $Domain." 'Success'
        Update-CredBanner
        return $true
    }
    catch {
        $msg = Get-ErrorText $_
        if ($previous) { $script:Creds[$key] = $previous } else { $script:Creds.Remove($key) }
        $script:DomainInfo.Remove($key)
        Write-Log "Credentials for $Domain were rejected: $msg" 'Error'
        Show-Failure "Those credentials were not accepted by ${Domain}:`r`n`r`n$msg"
        Update-CredBanner
        return $false
    }
}

function Test-DomainReachable {
    <#
        Binds to the domain, and if that fails offers the credential prompt
        once. Returns $true when the domain can be queried.
    #>
    param([string]$Domain, [switch]$NoPrompt)
    try { [void](Get-DomainInfo -Domain $Domain); return $true }
    catch {
        $msg = Get-ErrorText $_
        Write-Log "Cannot query $Domain with the current credentials: $msg" 'Warning'
        if ($NoPrompt) { return $false }
        if (-not (Confirm-Action ("$Domain did not accept the current credentials:`r`n`r`n$msg`r`n`r`nSupply credentials for $Domain now?"))) {
            return $false
        }
        return (Set-DomainCredential -Domain $Domain -Reason "$Domain refused the logged-on account. It is a separate forest, so it usually needs its own account.")
    }
}

function Invoke-Search {
    $text = $script:TxtSearch.Text.Trim()
    if (-not $text) { Show-Warn 'Type a sAMAccountName, a display name or a first name to search for.'; $script:TxtSearch.Focus(); return }
    if ($text.Length -lt 2 -and $text -notmatch '\*') {
        Show-Warn 'Type at least two characters (or use a * wildcard).'
        return
    }

    Set-Busy $true
    try {
        $script:Users = @()
        $script:Selected = $null
        $script:DcRows = @()
        Render-Dcs
        Update-SelectedBanner

        $mode = [string]$script:CboMode.SelectedItem
        $includeDisabled = [bool]$script:ChkDisabled.Checked
        $targets = Get-SelectedDomains
        $all = New-Object System.Collections.Generic.List[object]
        $problems = New-Object System.Collections.Generic.List[string]
        $n = 0
        foreach ($d in $targets) {
            $n++
            Set-Progress ($n - 1) $targets.Count
            Set-Status "Searching $d for '$text'..." 'Info'
            if (-not (Test-DomainReachable -Domain $d)) {
                $problems.Add("$d - not queried (no usable credentials)")
                continue
            }
            $res = Search-DomainUsers -Domain $d -Text $text -Mode $mode -IncludeDisabled $includeDisabled
            if ($res.Error) {
                $problems.Add("$d - $($res.Error)")
                Write-Log "Search failed in ${d}: $($res.Error)" 'Error'
                continue
            }
            foreach ($row in $res.Rows) { $all.Add($row) }
            if ($res.Truncated) { $problems.Add("$d - too many matches, the list was cut short") }
            Write-Log "$d returned $($res.Rows.Count) account(s) for '$text'." 'Info'
        }
        Set-Progress $targets.Count $targets.Count

        # Expired first, then closest to expiry - the order somebody working a
        # queue actually wants.
        $script:Users = @($all | Sort-Object -Property `
            @{Expression = { if ($null -ne $_.PwdDaysLeft) { $_.PwdDaysLeft } else { [int]::MaxValue } }}, `
            Domain, SamAccountName)
        Render-Users

        if ($script:Users.Count -eq 0) {
            $extra = if ($problems.Count) { "`r`n`r`n" + ($problems -join "`r`n") } else { '' }
            Set-Status "No account matched '$text'." 'Warning'
            Show-Warn "No account matched '$text'.$extra`r`n`r`nTry a * wildcard, or tick 'Include disabled accounts'."
        }
        else {
            $suffix = if ($problems.Count) { '  (' + ($problems -join '; ') + ')' } else { '' }
            Set-Status ("Found $($script:Users.Count) account(s) for '$text'." + $suffix) 'Success'
            # One hit is almost always the hit - select it so the operator can
            # go straight to the lockout scan or the reset.
            if ($script:GridUsers.Rows.Count -ge 1) {
                $script:GridUsers.Rows[0].Selected = $true
                Select-UserRow 0
            }
        }
    }
    finally {
        Set-Busy $false
        Set-Progress 0 0
    }
}

function Select-UserRow {
    param([int]$RowIndex)
    if ($RowIndex -lt 0 -or $RowIndex -ge $script:GridUsers.Rows.Count) { return }
    $script:Selected = $script:GridUsers.Rows[$RowIndex].Tag
    $script:DcRows = @()
    Render-Dcs
    Update-SelectedBanner
    Render-Rules
}

function Refresh-SelectedUser {
    <# Re-read the selected account so the grid reflects a reset / unlock. #>
    if (-not $script:Selected) { return }
    $u = $script:Selected
    $searcher = $null
    try {
        $de = New-DirEntry -Domain $u.Domain -Server (Get-PdcName -Domain $u.Domain) -DistinguishedName $u.DistinguishedName
        $searcher = New-Object System.DirectoryServices.DirectorySearcher($de)
        $searcher.SearchScope = 'Base'
        $searcher.Filter = '(objectClass=*)'
        [void]$searcher.PropertiesToLoad.AddRange($USER_ATTRS)
        $r = $searcher.FindOne()
        if (-not $r) { Set-Status 'The account could not be re-read from the PDC.' 'Warning'; return }
        $fresh = ConvertTo-UserRow -Result $r -Domain $u.Domain
        $script:Users = @($script:Users | ForEach-Object {
            if ($_.DistinguishedName -eq $fresh.DistinguishedName -and $_.Domain -eq $fresh.Domain) { $fresh } else { $_ }
        })
        Render-Users
        # Re-select the same account, by DN rather than by row number.
        foreach ($row in $script:GridUsers.Rows) {
            if ($row.Tag -and $row.Tag.DistinguishedName -eq $fresh.DistinguishedName) {
                $row.Selected = $true
                $script:Selected = $row.Tag
                break
            }
        }
        Update-SelectedBanner
        Render-Rules
    }
    catch { Write-Log ('Could not refresh the account: ' + (Get-ErrorText $_)) 'Warning' }
    finally { if ($searcher) { $searcher.Dispose() } }
}

function Invoke-LockoutScan {
    <#
        Asks EVERY domain controller in the account's domain, because
        badPwdCount and badPasswordTime are not replicated and lockoutTime only
        replicates urgently - so the DC that actually recorded the bad
        passwords is the one that answers "why does this keep locking".
    #>
    if (-not $script:Selected) { Show-Warn 'Select an account in the grid first.'; return }
    $u = $script:Selected

    Set-Busy $true
    $script:Cancel = $false
    try {
        Set-Status "Listing the domain controllers of $($u.Domain)..." 'Info'
        $dcs = @(Get-DomainControllerList -Domain $u.Domain)
        if ($dcs.Count -eq 0) { Show-Warn "No domain controller could be listed for $($u.Domain)."; return }
        # Measured at roughly 1.2s per DC through ZPA, so a full FTBCO scan is
        # about half a minute. Say so rather than letting it look hung - the
        # grid fills in as the answers arrive and Cancel Scan stops it.
        Write-Log ("Querying {0} domain controller(s) in {1} - expect around {2}s." -f `
            $dcs.Count, $u.Domain, [int]($dcs.Count * 1.2)) 'Info'

        $timeout = [int]$script:NumTimeout.Value
        $rows = New-Object System.Collections.Generic.List[object]
        $script:DcRows = @()
        $i = 0
        foreach ($dc in $dcs) {
            if ($script:Cancel) {
                Write-Log "Lockout scan cancelled after $i of $($dcs.Count) domain controller(s)." 'Warning'
                break
            }
            $i++
            Set-Progress $i $dcs.Count
            Set-Status ("Querying {0} ({1} of {2})..." -f $dc.Name, $i, $dcs.Count) 'Info'
            $res = Get-UserOnDc -Domain $u.Domain -Server $dc.Name -DistinguishedName $u.DistinguishedName -TimeoutSeconds $timeout
            $rows.Add([pscustomobject]@{
                Domain          = $u.Domain
                Dc              = $dc.Name
                Site            = $dc.Site
                IsPdc           = $dc.IsPdc
                Reachable       = [bool]$res.Ok
                LockState       = $(if (-not $res.Ok) { 'Unknown' } elseif ($res.LockedOut) { 'LOCKED' } else { 'Not locked' })
                LockoutTime     = $res.LockoutTime
                BadPwdCount     = $(if ($res.Ok) { [int]$res.BadPwdCount } else { 0 })
                BadPasswordTime = $res.BadPasswordTime
                PasswordLastSet = $res.PasswordLastSet
                Note            = [string]$res.Error
            })
            # Render as we go: on a slow link the first answers are useful long
            # before the last DC replies.
            $script:DcRows = $rows.ToArray()
            Render-Dcs
        }
        $script:DcRows = $rows.ToArray()
        Render-Dcs

        $answered = @($script:DcRows | Where-Object { $_.Reachable })
        $locked = @($answered | Where-Object { $_.LockState -eq 'LOCKED' })
        if ($answered.Count -eq 0) {
            Set-Status 'No domain controller answered - nothing could be checked.' 'Error'
            Write-Log "Lockout scan for $($u.SamAccountName): no DC answered." 'Error'
        }
        elseif ($locked.Count -gt 0) {
            $names = ($locked | ForEach-Object { $_.Dc }) -join ', '
            Set-Status ("LOCKED on {0} of {1} domain controller(s) that answered." -f $locked.Count, $answered.Count) 'Error'
            Write-Log "$($u.SamAccountName) is locked on: $names" 'Warning'
        }
        else {
            Set-Status ("Not locked on any of the {0} domain controller(s) that answered ({1} did not)." -f `
                $answered.Count, ($script:DcRows.Count - $answered.Count)) 'Success'
            Write-Log "$($u.SamAccountName) is not locked on any of the $($answered.Count) DC(s) that answered." 'Success'
        }
    }
    finally {
        Set-Busy $false
        Set-Progress 0 0
        $script:Cancel = $false
    }
}

function Invoke-Unlock {
    <#
        Unlocks on the PDC emulator plus every DC that reported LOCKED. The PDC
        is always included because it is the authoritative source for lockout;
        the others are included because a DC that has already recorded the lock
        locally will keep refusing the user until its own copy is cleared.
    #>
    if (-not $script:Selected) { Show-Warn 'Select an account in the grid first.'; return }
    $u = $script:Selected

    Set-Busy $true
    try {
        $pdc = Get-PdcName -Domain $u.Domain
        $targets = New-Object System.Collections.Generic.List[string]
        if ($pdc) { $targets.Add($pdc) }
        foreach ($d in $script:DcRows) {
            if ($d.Reachable -and $d.LockState -eq 'LOCKED' -and -not $targets.Contains($d.Dc)) { $targets.Add($d.Dc) }
        }
        if ($targets.Count -eq 0) { Show-Warn 'No domain controller could be determined to unlock on.'; return }

        $scanned = @($script:DcRows | Where-Object { $_.Reachable }).Count
        $note = if ($scanned -eq 0) {
            "`r`n`r`nThe per-DC scan has not been run, so only the PDC emulator will be cleared. Run 'Check All DCs' first to catch a DC holding its own copy of the lock."
        } else { '' }
        if (-not (Confirm-Action ("Unlock {0}\{1} ({2}) on:`r`n`r`n{3}`r`n`r`nProceed?{4}" -f `
            ($u.Domain -split '\.')[0], $u.SamAccountName, $u.DisplayName, ($targets -join "`r`n"), $note))) {
            Set-Status 'Unlock cancelled.' 'Info'
            return
        }

        $ok = 0; $failed = New-Object System.Collections.Generic.List[string]
        $i = 0
        foreach ($t in $targets) {
            $i++
            Set-Progress $i $targets.Count
            Set-Status "Unlocking on $t..." 'Info'
            $res = Unlock-UserOnDc -Domain $u.Domain -Server $t -DistinguishedName $u.DistinguishedName
            if ($res.Ok) { $ok++; Write-Log "Unlocked $($u.SamAccountName) on $t." 'Success' }
            else { $failed.Add("$t - $($res.Error)"); Write-Log "Unlock failed on ${t}: $($res.Error)" 'Error' }
        }

        if ($failed.Count -eq 0) {
            Set-Status "Unlocked on all $ok domain controller(s)." 'Success'
            Show-Info "$($u.SamAccountName) was unlocked on:`r`n`r`n$($targets -join "`r`n")"
        }
        else {
            Set-Status "Unlocked on $ok, failed on $($failed.Count)." 'Warning'
            Show-Warn ("Unlocked on $ok domain controller(s).`r`n`r`nFailed on:`r`n" + ($failed -join "`r`n"))
        }
        # Refresh-SelectedUser re-selects the row, which clears the DC grid, so
        # whether a scan had been run has to be remembered from before it.
        Refresh-SelectedUser
        if ($scanned -gt 0) { Invoke-LockoutScan }
    }
    finally {
        Set-Busy $false
        Set-Progress 0 0
    }
}

function Invoke-Reset {
    <#
        Written to the PDC emulator: a password reset applied there is
        immediately usable wherever the user authenticates, because every DC
        forwards a failed authentication to the PDC before rejecting it. Writing
        to a random DC instead leaves the user unable to sign in at another site
        until replication catches up.
    #>
    if (-not $script:Selected) { Show-Warn 'Select an account in the grid first.'; return }
    $u = $script:Selected
    $pwd1 = $script:TxtPwd1.Text
    $pwd2 = $script:TxtPwd2.Text

    if (-not (Test-PasswordAcceptable -Password $pwd1 -Confirm $pwd2 -User $u)) {
        $missing = @($script:Rules | Where-Object { -not $_.Met } | ForEach-Object { $_.Requirement })
        Show-Warn ("The new password does not meet every requirement:`r`n`r`n - " + ($missing -join "`r`n - "))
        return
    }

    $mustChange = [bool]$script:ChkMustChange.Checked
    $unlockToo = [bool]$script:ChkUnlockToo.Checked
    $summary = @(
        'Account  : {0}\{1}' -f ($u.Domain -split '\.')[0], $u.SamAccountName
        'Name     : {0}' -f $u.DisplayName
        'Domain   : {0}' -f $u.Domain
        'Current  : {0}' -f $u.PwdStatus
        ''
        'Set a new password{0}{1}.' -f `
            $(if ($mustChange) { ', forcing a change at next logon' } else { '' }), `
            $(if ($unlockToo) { ' and unlock the account' } else { '' })
    ) -join "`r`n"
    if (-not (Confirm-Action ($summary + "`r`n`r`nProceed?"))) { Set-Status 'Reset cancelled.' 'Info'; return }

    Set-Busy $true
    try {
        $pdc = Get-PdcName -Domain $u.Domain
        if (-not $pdc) { Show-Failure "The PDC emulator of $($u.Domain) could not be determined, so the reset was not attempted."; return }

        Set-Progress 1 3
        Set-Status "Resetting the password on $pdc..." 'Info'
        # NOTE: the password itself is never written to the log.
        Write-Log "Resetting the password of $($u.SamAccountName) in $($u.Domain) on $pdc." 'Info'
        $res = Set-UserPasswordOnDc -Domain $u.Domain -Server $pdc `
            -DistinguishedName $u.DistinguishedName -SamAccountName $u.SamAccountName -NewPassword $pwd1
        if (-not $res.Ok) {
            Write-Log "Password reset FAILED for $($u.SamAccountName): $($res.Error)" 'Error'
            Set-Status 'The password reset failed.' 'Error'
            Show-Failure ("The password of $($u.SamAccountName) was NOT changed.`r`n`r`n$($res.Error)`r`n`r`n" +
                "Common causes: the account you are using may not reset passwords in $($u.Domain), or the new password repeats one in the account's password history.")
            return
        }
        Write-Log "Password reset succeeded for $($u.SamAccountName) via $($res.Method)." 'Success'

        $warnings = New-Object System.Collections.Generic.List[string]
        Set-Progress 2 3
        if ($mustChange) {
            $r2 = Set-MustChangeAtLogon -Domain $u.Domain -Server $pdc -DistinguishedName $u.DistinguishedName
            if ($r2.Ok) { Write-Log "$($u.SamAccountName) must change the password at next logon." 'Success' }
            else { $warnings.Add("Could not set 'must change at next logon': $($r2.Error)"); Write-Log "Could not set pwdLastSet=0: $($r2.Error)" 'Warning' }
        }
        if ($unlockToo) {
            $r3 = Unlock-UserOnDc -Domain $u.Domain -Server $pdc -DistinguishedName $u.DistinguishedName
            if ($r3.Ok) { Write-Log "$($u.SamAccountName) unlocked on $pdc." 'Success' }
            else { $warnings.Add("Could not unlock the account: $($r3.Error)"); Write-Log "Unlock failed on ${pdc}: $($r3.Error)" 'Warning' }
        }
        Set-Progress 3 3

        # Do not leave the new password sitting in two text boxes.
        $script:TxtPwd1.Clear(); $script:TxtPwd2.Clear()
        Render-Rules
        Refresh-SelectedUser

        if ($warnings.Count -eq 0) {
            Set-Status "Password reset for $($u.SamAccountName) on $pdc." 'Success'
            Show-Info ("The password of {0} ({1}) was reset on {2}.`r`n`r`n{3}{4}`r`nAllow a few minutes for replication to the other domain controllers." -f `
                $u.SamAccountName, $u.DisplayName, $pdc,
                $(if ($mustChange) { "The user must change it at next logon.`r`n" } else { '' }),
                $(if ($unlockToo) { "The account was unlocked.`r`n" } else { '' }))
        }
        else {
            Set-Status 'Password reset, but some follow-up steps failed.' 'Warning'
            Show-Warn ("The password WAS reset, but:`r`n`r`n - " + ($warnings -join "`r`n - "))
        }
    }
    finally {
        Set-Busy $false
        Set-Progress 0 0
    }
}

function Get-ExportRows {
    param([ValidateSet('Accounts', 'DomainControllers')][string]$What)
    switch ($What) {
        'Accounts' {
            @($script:Users | ForEach-Object {
                [pscustomobject]@{
                    Domain            = $_.Domain
                    SamAccountName    = $_.SamAccountName
                    DisplayName       = $_.DisplayName
                    Enabled           = $(if ($_.Enabled) { 'Enabled' } else { 'DISABLED' })
                    PasswordStatus    = $_.PwdStatus
                    PasswordLastSet   = (Format-AdDate $_.PasswordLastSet)
                    PasswordExpiresOn = (Format-AdDate $_.PwdExpiresOn)
                    DaysLeft          = $(if ($null -ne $_.PwdDaysLeft) { $_.PwdDaysLeft } else { '' })
                    LockedOut         = $(if ($_.LockedOut) { 'LOCKED' } else { 'No' })
                    LockoutTime       = (Format-AdDate $_.LockoutTime)
                    BadPwdCount       = $_.BadPwdCount
                    LastBadPassword   = (Format-AdDate $_.BadPasswordTime)
                    Email             = $_.Mail
                    UserPrincipalName = $_.UserPrincipalName
                    Department        = $_.Department
                    Title             = $_.Title
                    LastLogon         = (Format-AdDate $_.LastLogon)
                    AccountExpires    = (Format-AdDate $_.AccountExpires)
                    PasswordPolicy    = $(if ($_.Pso) { $_.Pso } else { 'Domain default' })
                    DistinguishedName = $_.DistinguishedName
                }
            })
        }
        'DomainControllers' {
            @($script:DcRows | ForEach-Object {
                [pscustomobject]@{
                    Domain           = $_.Domain
                    DomainController = $_.Dc
                    Site             = $_.Site
                    Role             = $(if ($_.IsPdc) { 'PDC emulator' } else { '' })
                    Answered         = $(if ($_.Reachable) { 'Yes' } else { 'No' })
                    LockState        = $_.LockState
                    LockoutTime      = (Format-AdDate $_.LockoutTime)
                    BadPwdCount      = $(if ($_.Reachable) { $_.BadPwdCount } else { '' })
                    LastBadPassword  = (Format-AdDate $_.BadPasswordTime)
                    PasswordLastSet  = (Format-AdDate $_.PasswordLastSet)
                    Note             = $_.Note
                }
            })
        }
    }
}

function Save-ExportFile {
    param([string]$Path, [string]$What, $Data)
    $export = @($Data)
    $who = if ($script:Selected) { '{0}\{1} ({2})' -f ($script:Selected.Domain -split '\.')[0], $script:Selected.SamAccountName, $script:Selected.DisplayName } else { 'n/a' }
    $stamp = Get-Date -Format 'yyyy-MM-dd HH:mm:ss'

    switch ([System.IO.Path]::GetExtension($Path).ToLowerInvariant()) {
        '.txt' {
            $header = @(
                "Report    : $What"
                "Account   : $who"
                "Generated : $stamp by $env:USERDOMAIN\$env:USERNAME"
                ''
            )
            ($header + ($export | Format-Table -AutoSize | Out-String -Width 4096)) |
                Set-Content -LiteralPath $Path -Encoding UTF8 -ErrorAction Stop
        }
        '.html' {
            $style = @'
<style>
 body { font-family: "Segoe UI", Arial, sans-serif; color:#323232; background:#f0f0f0; padding:20px; }
 h2 { color:#323232; margin-bottom:4px; }
 table { border-collapse:collapse; width:100%; background:#ffffff; }
 th { background:#e1ebf5; color:#323232; text-align:left; padding:8px; border:1px solid #cccccc; }
 td { padding:6px 8px; border:1px solid #dddddd; color:#323232; }
</style>
'@
            $pre = '<h2>{0}</h2><p>Account: {1}<br/>Generated {2}</p>' -f $What, $who, $stamp
            $html = $export | ConvertTo-Html -Head $style -PreContent $pre | Out-String
            # Colour the verdict cells to match the on-screen grid.
            $html = $html -replace '<td>(LOCKED|DISABLED)</td>', '<td style="background:#ffc8c8;font-weight:bold">$1</td>'
            $html = $html -replace '<td>(EXPIRED[^<]*)</td>', '<td style="background:#ffc8c8;font-weight:bold">$1</td>'
            $html = $html -replace '<td>(Must change at next logon|Never expires|Expires today|Unknown[^<]*)</td>', '<td style="background:#fff5c8">$1</td>'
            $html = $html -replace '<td>(Not locked|Enabled)</td>', '<td style="background:#c8ffc8">$1</td>'
            $html | Set-Content -LiteralPath $Path -Encoding UTF8 -ErrorAction Stop
        }
        default {
            $export | Export-Csv -LiteralPath $Path -NoTypeInformation -Encoding UTF8 -ErrorAction Stop
        }
    }
}

function Export-Data {
    param([ValidateSet('Accounts', 'DomainControllers')][string]$What)
    $data = Get-ExportRows -What $What
    if (-not $data -or $data.Count -eq 0) {
        Show-Warn $(if ($What -eq 'Accounts') { 'Search for an account first - there is nothing to export.' }
                    else { "Run 'Check All DCs' first - no domain controller has been queried yet." })
        return
    }

    $who = if ($script:Selected) { ($script:Selected.SamAccountName -replace '[^\w\.\-]', '_') } else { 'search' }
    $dlg = New-Object System.Windows.Forms.SaveFileDialog
    $dlg.Title = "Export $What"
    $dlg.Filter = 'CSV file (*.csv)|*.csv|Text file (*.txt)|*.txt|HTML report (*.html)|*.html'
    $dlg.FileName = 'PasswordExpiry_{0}_{1}_{2:yyyyMMdd_HHmmss}.csv' -f $What, $who, (Get-Date)
    if (Test-Path -LiteralPath $script:WorkFolder) { $dlg.InitialDirectory = $script:WorkFolder }
    if ($dlg.ShowDialog() -ne 'OK') { return }

    $path = $dlg.FileName
    try {
        Save-ExportFile -Path $path -What $What -Data $data
        Write-Log "Exported $What ($($data.Count) row(s)) to $path" 'Success'
        Set-Status "Exported $($data.Count) row(s) to $path" 'Success'
        if (Confirm-Action "Export saved to:`r`n$path`r`n`r`n$($data.Count) row(s) written.`r`n`r`nOpen it now?") { Invoke-Item -LiteralPath $path }
    }
    catch {
        $msg = Get-ErrorText $_
        Write-Log "Export failed: $msg" 'Error'
        Show-Failure "Could not save the export to:`r`n$path`r`n`r`n$msg"
    }
}

# ============================================================================
# Wire up events (each handler is self-contained and never lets an error escape)
# ============================================================================

function Invoke-Safely {
    param([scriptblock]$Action, [string]$What)
    try { & $Action }
    catch {
        $msg = Get-ErrorText $_
        Write-Log "$What failed unexpectedly: $msg" 'Error'
        Set-Status "$What failed." 'Error'
        Show-Failure "Something went wrong while doing: $What`r`n`r`n$msg"
    }
    finally { if ($script:Busy) { Set-Busy $false } }
}

$btnCreds.Add_Click({
    Invoke-Safely {
        # Which domain the credential is for: obvious with one domain, asked
        # for otherwise by using whatever is selected in the picker.
        $d = [string]$script:CboDomain.SelectedItem
        if ($d -eq $ALL_DOMAINS) {
            Show-Info "Credentials are per domain.`r`n`r`nPick the single domain they are for in the Domain box, then click Credentials... again."
            return
        }
        [void](Set-DomainCredential -Domain $d)
    } 'Set credentials'
})

$script:Form.Add_Shown({
    Invoke-Safely {
        if (-not (Test-Path -LiteralPath $script:WorkFolder)) {
            [void](New-Item -ItemType Directory -Path $script:WorkFolder -Force -ErrorAction SilentlyContinue)
        }
        Write-Log "Session started by $env:USERDOMAIN\$env:USERNAME. Working folder: $script:WorkFolder" 'Info'
        Write-Log ("Domains in the picker: " + ($Domains -join ', ')) 'Info'
        Update-CredBanner
        Update-SelectedBanner
        Render-Rules
        Render-Dcs

        # Bind to each domain once now, so "FTBTST.LOCAL will need its own
        # account" is on screen before somebody types a name and waits.
        foreach ($d in $Domains) {
            if (Test-DomainReachable -Domain $d -NoPrompt) {
                $info = Get-DomainInfo -Domain $d
                $policy = if ($info.MaxPwdDays) { "max age $($info.MaxPwdDays) days" } else { 'passwords do not expire by policy' }
                Write-Log ("{0}: reachable (bound to {1}), min length {2}, {3}, lockout threshold {4}." -f `
                    $d, $info.BoundTo, $info.MinPwdLen, $policy, $info.LockoutMax) 'Success'
            }
            else {
                Write-Log "${d}: the logged-on account was refused - use 'Credentials...' before searching it." 'Warning'
            }
        }
        Set-Status 'Ready. Type a sAMAccountName, display name or first name and press Enter.' 'Info'
        $script:TxtSearch.Focus()
    } 'Startup'
})

# ShowDialog runs its own message pump, so left-over handlers from other GUI
# scripts sharing this runspace can also throw there. Route those to the log
# instead of the "Unhandled exception has occurred in a component" dialog, and
# detach again afterwards so the calling menu is left exactly as it was.
$script:ThreadExceptionHandler = [System.Threading.ThreadExceptionEventHandler]{
    param($eventSender, $e)
    $detail = ('{0}' -f $e.Exception.Message) -replace '\s+', ' '
    try { Write-Log "Ignored an error raised by another script in this session: $detail" 'Warning' } catch { }
}
try {
    [System.Windows.Forms.Application]::SetUnhandledExceptionMode([System.Windows.Forms.UnhandledExceptionMode]::CatchException)
}
catch { }   # already set, or a window exists in this process - not fatal
try { [System.Windows.Forms.Application]::add_ThreadException($script:ThreadExceptionHandler) } catch { }

try {
    # Raised 3D faces, the shared light palette and the hover animation. Runs
    # last, once every control exists: it walks the control tree and takes over
    # painting for the buttons, group boxes, grid headers and text boxes.
    Set-Gui3DTheme -Target $script:Form @script:G3DThemeArgs

    # Keep the status wash on the SELECTED row.
    #
    # Set-G3DGrid adds a CellPainting handler that fills every selected cell
    # with a gradient built from one fixed Selection colour, so it paints
    # straight over whatever the render put there - and SelectionBackColor is
    # never consulted. On these grids that is not cosmetic: the row the
    # operator just clicked is the one row whose "EXPIRED" and "LOCKED" cells
    # go blank, which is exactly the row they clicked in order to read.
    #
    # Handlers fire in the order they were added, so this one runs after the
    # theme's and gets the last word. It keeps the raised gradient - just built
    # from the cell's own wash, which Set-CellWash left on the cell's Tag - so
    # the grids still look like every other tool here.
    $washPainter = {
        param($sender, $e)
        if ($e.RowIndex -lt 0 -or $e.ColumnIndex -lt 0) { return }
        if (-not ($e.State -band [System.Windows.Forms.DataGridViewElementStates]::Selected)) { return }
        try {
            $cell = $sender.Rows[$e.RowIndex].Cells[$e.ColumnIndex]
            $wash = $cell.Tag
            if (-not ($wash -is [System.Drawing.Color])) { return }
            $r = $e.CellBounds
            if ($r.Width -le 0 -or $r.Height -le 0) { return }

            if (Get-Command Get-Gui3DShade -ErrorAction SilentlyContinue) {
                $top = Get-Gui3DShade -Color $wash -Amount 0.22
                $bottom = Get-Gui3DShade -Color $wash -Amount -0.10
            }
            else { $top = $wash; $bottom = $wash }

            $brush = New-Object System.Drawing.Drawing2D.LinearGradientBrush($r, $top, $bottom, 90.0)
            try { $e.Graphics.FillRectangle($brush, $r) } finally { $brush.Dispose() }

            # Repaint only the text and the border on top of our own fill, so
            # the value stays readable without re-implementing text layout.
            $e.Paint($e.ClipBounds,
                ([System.Windows.Forms.DataGridViewPaintParts]::ContentForeground -bor
                 [System.Windows.Forms.DataGridViewPaintParts]::Border))
            $e.Handled = $true
        }
        catch { }
    }
    $script:GridUsers.Add_CellPainting($washPainter)
    $script:GridDcs.Add_CellPainting($washPainter)
    $script:GridRules.Add_CellPainting($washPainter)

    [void]$script:Form.ShowDialog()
}
finally {
    try { [System.Windows.Forms.Application]::remove_ThreadException($script:ThreadExceptionHandler) } catch { }
    # Tear the shared animation state down unconditionally before this script's
    # scope - and with it every function the theme library defined - goes away.
    # The library already does this from FormClosed, but only for forms it
    # knows about, and only if that event actually ran. See the note beside
    # $script:G3DThemeArgs: anything of the library's still armed after this
    # point fires inside the HOST's message pump, where its functions no longer
    # exist.
    try { Stop-G3DAnimation } catch { }
    $script:Form.Dispose()
}
