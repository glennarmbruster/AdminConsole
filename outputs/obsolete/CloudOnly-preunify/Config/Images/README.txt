Logos go here.

A logo named for the connected tenant is preferred over the generic one:

    logo.<tenant-domain>.png    used when connected to that domain
                                e.g. logo.contoso.com.png
    logo.png                    used when no tenant-specific file matches

The domain comes from whatever tenant the console is connected to, so one copy
of this toolkit can serve several tenants and show the right logo for each.

PNG keeps transparency. A JPG logo shows a white box on a coloured console.
Anything that is not PNG, JPG, GIF or BMP is ignored.
