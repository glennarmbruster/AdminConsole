WHAT CHANGED. A tool is now HIDDEN, not greyed, when the tenant's own
Capabilities say it has no such thing. Greying still means 'could work once
you connect'. Two different facts, two different signals.

Hybrid tenants see NO change: every capability is ticked, so nothing hides.

--------------------------------------------------------------------------
SETUP  (5 minutes)
--------------------------------------------------------------------------
1. Copy TenantConfigs\Tenant.gcearth.json to the install's
   Config\Tenants\gcearth.json
2. Launch:  .\AdminConsole.ps1 -Tenant gcearth
3. Nothing else. Do NOT edit Tools.json.

To undo: launch with -Tenant against a hybrid tenant as usual. Nothing in
this batch touches hybrid behaviour.

THE ACTUAL TEST -- 8 tools that STAY and must degrade gracefully
--------------------------------------------------------------------------
These declare TOOLKIT-VARIANT: Dual, so they are never hidden -- they are
supposed to handle the missing half themselves. This is the list worth your
time. Open each, load a real cloud object, and answer one question:

    Does it work cloud-side, and does it SAY why the on-prem part is
    absent -- or does it throw / show a blank grid / silently do nothing?

  1. Mailbox Editor      Load a mailbox. Editing switch should sit on Cloud
                         and be disabled. Walk every tab. Overview, Health,
                         Addresses, Access matter most.
  2. Person Editor       Load a user. Expect read-only with a plain reason
                         on the banner, not an error dialog.
  3. Group Editor        Load a cloud group. Members, owners, addresses.
  4. Hide / Unhide       Should write cloud-side without asking about AD.
  5. DL to SharedMB      Cloud path only.
  6. Hybrid Attribute Check   Should say 'nothing to compare', not fail.
  7. Diagnose ExO Resolve     Should still diagnose the cloud half.
  8. Group Manager Editor     (being parked anyway -- lowest priority)

ALSO WORTH ONE PASS:
  Unified Lookup (Look Up box, top of the console). Not in Tools.json so it
  is never hidden. Search a name. The Source column should not claim
  'Synced' or 'On-prem' anywhere, and the bottom buttons should route
  sensibly. I expect this one to need work -- it is the most likely finding.

--------------------------------------------------------------------------
WHAT COUNTS AS A FINDING
--------------------------------------------------------------------------
  BAD   A red error, an empty grid with no explanation, a hang, or a button
        that does nothing.
  BAD   A tool that is hidden but shouldn't be, or visible but can't work.
  FINE  A tool that opens, works cloud-side, and says in words that the
        on-premises part is not available here.

For each finding I need: tool name, what you did, what happened. The exact
error text if there is one.

  appear on next launch with nothing else changing. Worth testing once the
